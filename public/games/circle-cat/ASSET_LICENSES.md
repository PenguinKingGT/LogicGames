The game uses only selected frames from the original `01_Idle` and `02_Run`
folders. Hurt, jump, fall, and dead animations are not included.

Transformations:

- Idle source frames 000, 003, 006, and 009 were renamed to `idle-0.png`
  through `idle-3.png`.
- Run source frames 000, 002, 004, 006, and 008 were renamed to `run-0.png`
  through `run-4.png`.
- Every selected frame was cropped consistently from the original transparent
  489 by 461 canvas to 280 by 380, then proportionally resized to a maximum
  dimension of 192 pixels using macOS `sips`.
